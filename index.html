Deployment checklist

  1. Connect the repository to the gnaitv Cloudflare Pages project.
  2. Leave the build command empty and use . as the output directory.
  3. Set the production environment variables for YouTube uploads only when ready.
  4. Verify /api/health, /api/live, and /api/youtube-uploads after each deployment.

Deploy static files and the root functions/ directory together on Cloudflare Pages.
