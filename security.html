Architecture

Security core layout

  • File Inspection Engine: SHA-256, signatures, entropy signal, allow/review/block
  • Quarantine Service: isolated evidence handling and administrator review
  • Privacy Auditor: header policy, cookie classification, tracker detection, audit event
  • Evidence Ledger: timestamped append-only decision records
  • GNAI TV Admin: Cloudflare Access, authorized identity, MFA/passkey, default deny
Milestone order

Implementation guidance

  • Build checksum and evidence logging before any privileged interception research.
  • Integrate security telemetry into the admin dashboard first.
  • Use entropy as a suspicious-review signal, not automatic ransomware proof.
  • Do not represent header filtering as completed GDPR compliance.

Production access should remain behind Cloudflare Access with owner-controlled review.
