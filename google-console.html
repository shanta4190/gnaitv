Safe setup

Google Console and YouTube checklist

Configure uploads without exposing secrets in the repository, screenshots, or chat.

Production setup flow

  1. Create or select the GNAI TV project in Google Cloud Console.
  2. Enable only the YouTube Data API v3.
  3. Create a restricted API key for that API.
  4. Find the public YouTube channel ID that begins with UC.
  5. Add the values to Cloudflare Pages production variables.
  6. Redeploy the site after the variables are saved.

Variables used by this site

  • YOUTUBE_API_KEY
  • YOUTUBE_CHANNEL_ID
  • GNAITV_LIVE_VIDEO_ID (optional)

Safety rules

  • Never commit secrets or store them in version control.
  • Do not paste credentials into issues, pull requests, or chat.
  • Keep live mode disabled until the broadcast source is verified.

Credential handling stays inside Cloudflare production variables.
