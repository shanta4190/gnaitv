Google Console

Safe setup checklist

Configure YouTube upload metadata on the server side without exposing API keys in the browser.

  • Home
  • Watch
  • Channels
  • YouTube Media

Checklist

  1. Create or select the GNAI TV project in Google Cloud Console.
  2. Enable YouTube Data API v3 only.
  3. Create an API key and restrict it to that API.
  4. Copy the public YouTube channel ID beginning with UC.
  5. Store both values in Cloudflare Pages Production variables.
  6. Redeploy after updating variables.
Do not commit or paste API credentials into the repository, screenshots, or chat.
